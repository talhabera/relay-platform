# Design

<!-- impeccable:design-schema 1 -->

## World

Trading-desk blotter for an agency operator: paper under cool office LEDs, two books (Channels / Desk), ink as the only action color, amber lamps for live risk. Not a crypto terminal and not dusty-blue Inter SaaS.

## Type

Source Sans 3 everywhere. Headings 600 / -0.02em. Stamps 10px, 600, 0.08em uppercase, tabular figures. No display serif. No Inter.

## Color

Restrained. Light paper `#ebe4d4`, ink `#191512`, muted `#5c5348`. Dark carbon `#141210`, paper ink `#ebe4d4`. Lamp `#b85a12` / `#e09148` for live/approval only. Radius 2px tickets.

## Chrome

Sidebar grouped Desk / Channels / Admin / Account. Overlay header on app pages. Chat and Inbox are bleed panes. Config pages are sheets with a title block (no eyebrows).

## Motion

150–250ms state changes only. Reduced motion: instant.

## Anti-references

Incumbent dusty blue, Create-account CTAs, fake blog links, equal five-tab agent settings, full-card overlay links fighting delete.
